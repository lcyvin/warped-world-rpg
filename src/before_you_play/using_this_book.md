# Using This Book

Warped World provides the tools necessary to run a roleplaying campaign in an SCP
universe setting. The resources provided within should be enough for you to play 
your very own SCP adventure, but you are also welcome to extend and modify what you see
here. As with the universe itself, nothing is set in stone. If you wish to run this 
game as a playtest, please consider providing feedback via the author’s email, 
<a href="mailto:author@warpedworldrpg.com">author@warpedworldrpg.com</a>, or submit an
issue, pull request, or RFC to the game's source repository on
[github](https://github.com/lcyvin/warped-world-rpg/issues).
