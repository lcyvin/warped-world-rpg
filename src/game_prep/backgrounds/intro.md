# Backgrounds

The following provided backgrounds represent a basic set of generalized archetypes which
occur within the broad fiction of SCP. They are designed to provide a solid jumping-off
point for creating a broad range of player characters, without enforcing too much specific
flavor on any one archetype. If you as a player or GM desire to create more specific,
focussed backgrounds for your character(s), feel free to use the provided backgrounds as a
jumping-off point for designing your own.
